# AWR 0.5.0

[English](0.5.0.md)

本版改善日常工作导航、MCP 工具发现和会话接续指引，包含 #27、#28、#29、#30、
#31、#33、#48、#53 八个 PR。保留个人 Workspace 文件交换和既有共享 HTTP MCP
服务，新增 Team 实现不在本次发行范围。

## 使用变化

- **日常导航**：行动视图区分当前、可认领、等待和阻塞的工作；历史验证保留真实依据。
  `work edit` 可预览常用字段的小幅修改，诊断提供具体恢复步骤。
- **MCP 工具发现**：默认分组模式为 stdio 8 个、HTTP 9 个工具；flat 兼容模式为
  stdio 32 个、HTTP 33 个。按需发现操作，既有必需上下文和完成条件继续生效。
- **精准接续指引**：指引包含适用条件、依据、下一步动作和重新判断的触发条件。
  保持宿主原生压缩开启，根据实际压缩后的上下文占用记录提出建议；默认 50% 是可配置的
  启发式阈值。缺少宿主数据时保留未知，需要换会话时由用户授权交接。
- **个人跨机器 Workspace**：通过对象存储交换文件，各机器保留独立运行态。
  不同步运行中的 SQLite，也不提供 Team 权限、调度或语义合并。
- **宿主接入分层**：L0 是通用 CLI/MCP 合同，L1 是宿主接入说明，L2 是可选适配器。
  Cursor 属于 L1 接入，生命周期自动化仍取决于宿主能力。
- **可选 Inspector**：从源码运行本地查看界面，不进入 npm/PyPI 安装包，也不增加启动命令。
  查询可能刷新 SQLite 投影，并非运行态只读；显式重索引默认关闭。
- **Linux ARM64**：预编译包扩展至五个平台，继续支持 Apple Silicon 和 Intel Mac。
  Linux 两种架构都要求 glibc 2.39+，即 Ubuntu 24.04 基线。

## 从 0.4.0 升级

```sh
npm install -g @originoneai/agent-work-runtime@0.5.0
# 或在 Python 虚拟环境中
python -m pip install agent-work-runtime==0.5.0
```

需要调整三处兼容用法：

1. `status` / `awr_project_status` 默认返回行动视图。依赖旧版完整结构的集成，显式使用
   `status --view full` / `view: "full"`。
2. MCP 默认 grouped。依赖原有平铺工具名的客户端，可为服务设置
   `AWR_MCP_TOOL_EXPOSURE_MODE=flat`，随后重连以刷新工具发现。
3. `client bind/progress/show/hook/install` 必须显式提供 `--client`。
   先查看 `awr client <命令> --help`，更新依赖默认客户端的脚本。

数据库 schema 仍为 **4**。升级前停止写入者，保留匹配的旧程序、配置、权威来源和完整
SQLite/运行态快照，按[升级与回滚流程](DISTRIBUTIONS.md#matched-upgrade-and-rollback-checklist)
操作。schema 相同或版本号正确，都不能单独证明可安全回滚。

启动器需要 Node 22.14+ 或 Python 3.9+；macOS 需要 15+，Windows 为 x64。
完整边界见[发行说明](DISTRIBUTIONS.md)、[日常工作](../reference/daily-work.md)、
[上下文接续](../integrations/context-continuity.md)、
[Workspace](../reference/workspace-exchange.md)、[宿主分层](../integrations/README.md)
和 [Inspector](../../tools/inspector/README.md)。

## 验证口径

发行流程校验八个 crate 的范围、版本和发布身份，五平台原生检查、Inspector 测试和
npm/pip 安装回执通过后才组装发布物。六个 npm 压缩包、五个 wheel、清单和 SHA256
校验文件绑定同一个源码 SHA，并使用相同的已验证文件发布。

这些检查证明原生程序及安装包的行为，不代表所有宿主的完整生命周期或独立业务验收。
本版不承诺无限上下文，也不把合成测试结果解释为实际模型费用、token 或执行时间的改善。
