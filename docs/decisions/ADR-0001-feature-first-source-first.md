# ADR-0001：功能优先与 Source-first 开工基线

Status: accepted
Date: 2026-09-08

## 决定

采用完整 V1 范围，保留原始设计快照，按 P0 功能、P1 Agent 接入、P2 安全与集中测试、P3 发布安排工作。功能阶段运行必要的直接检查；完整回归和专项加固集中后置。

权威台账采用 YAML，与拟实现的 yaml-ledger-v1 适配器保持兼容方向；范围、计数及场景硬门槛由 JSON 机器合同定义。Markdown 索引从二者生成。Python 校验器仅服务筹备治理，产品运行时仍采用 Rust。

## 理由与影响

该顺序响应当前功能优先要求，尽早验证“读取当前工作 → 编译最小上下文 → 跨会话恢复”的价值。版本/指纹绑定、硬规则保留和真实证据是对应功能正确性的一部分。专项安全和系统测试继续作为 V1 必需任务保留。

59 个 V1 条目、3 个筹备条目与 8 个真实业务场景分别计数；不把计划覆盖或本地校验升级为产品实现和真实验收结论。
