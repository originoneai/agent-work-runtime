# AWR documentation

- **`series/`** — the user-facing documentation series, published on the
  [official website](https://awr.originoneai.com/docs/). Start here to install
  and use AWR.
- **`dev/`** — engineering records kept during development: design contracts,
  workstream notes, verification matrices and release checklists. Written for
  contributors; it is an archive, not a learning path.
- **`assets/`** — images shared by the README and the documents above.
