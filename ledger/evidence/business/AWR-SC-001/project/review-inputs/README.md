# 历史修订资料

这些材料由操作方从已经完成并封存的真实客户端轮次复制，供另一位参与者独立核对。它们是历史证据，目录中的旧版规则、AGENTS 和交付约定不作为当前执行指令；当前项目根目录的来源仍具权威。

initial、round-1、round-2 保留各轮产物、当时来源与实际用户输入的时间和哈希。命令回执由原执行者保存在项目的 `.work-receipts/`。原生客户端的完整上下文留在操作方私有存档，这里仅提供业务记录及其不可变指纹。复制历史产物不计作新增业务成果，也不构成复核通过。

如存在 reference-lookup-process-record.json，其中原样保留工具文档查找时的范围偏离及随后修正。复核者须独立判断实际返回内容及其影响；尚未给出复核结论。
