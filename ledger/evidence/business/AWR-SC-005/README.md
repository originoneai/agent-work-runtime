# 帮助中心材料使用、复核与交付

这份记录来自 2026-09-09 的真实 Codex 文档协助使用与不同参与者的独立复核。先读[最终交付与责任移交](project/deliverables/yf-delivery.md)，再看[使用说明](project/deliverables/yunfan-usage-report.md)、[证据缺口](project/deliverables/yunfan-evidence-gaps.md)、[历史映射](project/deliverables/yunfan-delivery-receipt.md)与[独立复核](project/deliverables/yf-independent-review.md)。

实际处理三条项目输入；六个自拟检查问题不算用户追问。两轮计数来自实际客户端收到的独立业务返工请求。输入表到达时间、问题作者与修改对象的旧错误均保留并纠正。源材料修改和外部账号、导入、反馈操作均为零，客户现场来源仍未知。当前交付是可用说明、证据与未决责任，未声称真实系统成功。

[门槛审查](gate-review.json)保留待验证的远端门槛。单场独立提交推送并核验后，后续 acceptance.json 才绑定交付 SHA 并支持权威台账计数。

project/ 保存最终业务文件和回执，history/ 保存实际旧版本，control/ 保存业务提取与独立复核。[回执映射](receipt-storage.json)连接原始封存哈希和公开位置。完整原生上下文、记忆、思考、事件流和运行数据库留在本地；原始回执字节不被格式化改写。run.json 保留准备阶段事实，运行源码、业务来源和公开交付提交分别绑定。
